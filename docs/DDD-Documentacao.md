## 1. Linguagem Ubíqua (Ubiquitous Language)

Glossário de termos utilizados por todos os envolvidos (negócio e desenvolvimento):

| Termo | Definição |
|---|---|
| **Cliente** | Pessoa física (CPF) ou jurídica (CNPJ) que leva o veículo à oficina |
| **Veículo** | Automóvel identificado por placa (formato antigo ou Mercosul), marca, modelo e ano, vinculado a um cliente |
| **Ordem de Serviço (OS)** | Documento central que registra o atendimento: serviços solicitados, peças utilizadas, orçamento e status de andamento |
| **Número da OS** | Identificador sequencial único gerado automaticamente (ex: OS-20240601-0001) |
| **Serviço** | Tipo de trabalho oferecido pela oficina (ex: troca de óleo, alinhamento, balanceamento) com preço catalogado |
| **Peça / Insumo** | Material físico utilizado no reparo (ex: óleo 5W30, pastilha de freio), com controle de estoque |
| **Item de Serviço** | Snapshot de um serviço no momento da inclusão na OS, com preço unitário e quantidade |
| **Item de Peça** | Snapshot de uma peça no momento da inclusão na OS, com código, preço unitário e quantidade |
| **Orçamento** | Valor total da OS, calculado automaticamente pela soma dos itens de serviço e itens de peça |
| **Estoque** | Quantidade disponível de cada peça/insumo; controlado por operações de entrada e saída |
| **Entrada de Estoque** | Incremento na quantidade disponível de uma peça |
| **Saída de Estoque** | Decremento na quantidade disponível ao utilizar peça em uma OS |
| **Diagnóstico** | Etapa de análise do veículo para identificar problemas e definir serviços necessários |
| **Aprovação** | Ato do cliente de autorizar o orçamento para que a execução dos serviços inicie |
| **Status da OS** | Estado atual do atendimento no fluxo (Recebida, Em Diagnóstico, Aguardando Aprovação, Em Execução, Finalizada, Entregue, Cancelada) |
| **Usuário** | Funcionário do sistema (Administrador, Mecânico ou Recepcionista) que opera as APIs administrativas |
| **Perfil** | Papel do usuário no sistema: Administrador, Mecânico ou Recepcionista |
| **Token JWT** | Credencial de acesso gerada após login, obrigatória para endpoints administrativos |

## 4. Agregados (Aggregates)

| Agregado | Raiz | Componentes | Regras de Invariante |
|---|---|---|---|
| **OrdemServico** | `OrdemServico` | `ItemServico`, `ItemPeca` | Fluxo de status sequencial; não pode editar OS finalizada/entregue/cancelada; precisa de ?1 item para aprovação/finalização |
| **Cliente** | `Cliente` | `Documento` (VO) | CPF/CNPJ válido e único; nome obrigatório |
| **Veículo** | `Veículo` | `Placa` (VO) | Placa válida (antigo/Mercosul); vinculado a um cliente existente |
| **Peça** | `Peça` | — | Estoque ? 0; saída não pode exceder estoque disponível |
| **Serviço** | `Serviço` | — | Nome e descrição obrigatórios; preço ? 0 |
| **Usuário** | `Usuário` | — | Email único; senha criptografada com BCrypt |

## 5. Comandos e Eventos de Domínio

### Comandos (Commands)

| Comando | Ator | Descrição |
|---|---|---|
| CriarCliente | Recepcionista | Cadastra novo cliente com CPF/CNPJ validado |
| CriarVeículo | Recepcionista | Vincula veículo (placa validada) ao cliente |
| CriarOrdemServico | Recepcionista | Abre nova OS com status "Recebida" |
| AdicionarServicoNaOS | Mecânico/Recepcionista | Inclui item de serviço com snapshot do preço |
| AdicionarPecaNaOS | Mecânico/Recepcionista | Inclui item de peça com snapshot do preço |
| IniciarDiagnostico | Mecânico | Avança status para "Em Diagnóstico" |
| EnviarParaAprovacao | Mecânico | Envia orçamento ao cliente |
| AprovarOrcamento | Cliente | Autoriza execução dos serviços |
| FinalizarServico | Mecânico | Marca serviço como concluído |
| EntregarVeiculo | Recepcionista | Registra entrega do veículo |
| CancelarOS | Administrador | Cancela OS com motivo |
| EntradaEstoque | Administrador | Incrementa estoque de peça |
| SaidaEstoque | Sistema (automático) | Decrementa estoque ao incluir peça na OS |

### Eventos de Domínio (Domain Events)

| Evento | Disparado por | Efeito |
|---|---|---|
| OrdemServicoCriada | CriarOrdemServico | OS criada com status "Recebida" |
| ServicoAdicionadoNaOS | AdicionarServicoNaOS | Orçamento recalculado |
| PecaAdicionadaNaOS | AdicionarPecaNaOS | Orçamento recalculado, estoque verificado |
| DiagnosticoIniciado | IniciarDiagnostico | Status ? "EmDiagnostico", data registrada |
| OrcamentoEnviadoParaAprovacao | EnviarParaAprovacao | Status ? "AguardandoAprovacao" |
| OrcamentoAprovado | AprovarOrcamento | Status ? "EmExecucao" |
| ServicoFinalizado | FinalizarServico | Status ? "Finalizada", data registrada |
| VeiculoEntregue | EntregarVeiculo | Status ? "Entregue", data registrada |
| OrdemServicoCancelada | CancelarOS | Status ? "Cancelada", motivo registrado |
| EstoqueIncrementado | EntradaEstoque | Quantidade atualizada |
| EstoqueDecrementado | SaidaEstoque | Quantidade atualizada |
